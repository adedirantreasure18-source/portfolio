01 / Multi-tenant SaaS

WorkDeck

A work-order platform for facilities and maintenance teams. A firm signs up, gets its own workspace, raises jobs, assigns technicians — and keeps the evidence that the work got done.

  • 18-model Prisma schema, four roles, per-tenant query scoping
  • Preventive-maintenance schedules that raise their own jobs
  • Append-only timeline, manager sign-off, 30-day audit restore
  • REST API v1 with hashed, revocable keys; six Vitest suites
  • Installable PWA with offline mode; Docker + PostgreSQL deploy

02 / About

I like the parts
that have to be right.

I'm a full-stack developer in Lagos. I work mostly in TypeScript and Python, and I gravitate to problems where the hard part is the model rather than the paint: permissions, schedules, state machines, money moving between two places.

WorkDeck began because maintenance teams were running jobs off spreadsheets and group chats. I designed the schema, the role model and the API, built the interface and the tests, packaged it in Docker — then wrote the handover docs so another team could run it without me.
